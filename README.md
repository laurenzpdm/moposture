# Mo: Posture & Back Pain Relief

Source of the website for Mo, an iOS and Android app with gentle posture, neck, back and jaw routines, guided by a sloth coach.

- Website: https://laurenzpdm.github.io/moposture/
- All exercise guides: https://laurenzpdm.github.io/moposture/exercises/
- App Store: https://apps.apple.com/app/id6821570259
- Google Play: https://play.google.com/store/apps/details?id=com.thuemmlerai.posturepal

The guides are general information, not medical advice.
